# iPaaS – Integration Platform as a Service

A cloud-based platform that lets organizations integrate and manage applications, data and processes across on-premises
and cloud environments. It provides tools to connect disparate systems, automate workflows and exchange data without
extensive custom code or infrastructure management.

Compared with neighbours: an [ESB](monolith-vs-microservices.md#esb-vs-microservices) is a self-run, centralized
integration bus; an [API gateway](api-gateway.md) fronts your own APIs; [Kafka](../devops/kafka.md) moves event streams;
iPaaS is the managed, low-code way to wire SaaS and enterprise systems together.

Examples (verify current market): MuleSoft Anypoint, Boomi, Workato, SnapLogic, Celigo, Tray, Azure Logic Apps, and
(lighter weight) Zapier/Make.
