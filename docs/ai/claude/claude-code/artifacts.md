# Artifacts

A dedicated side panel where substantial output (code, documents, small apps) is rendered, edited and iterated on
separately from the chat stream. Same feature in Claude.ai and Claude Code.

- In Claude Code, publishing uploads the page to a shareable `claude.ai/code/artifact/...` URL; it is **not** stored in the
  local project or git repo.
- Use it for a deliverable you'll refine rather than a throwaway reply: a report to share, a prototype, a diagram.
- Every artifact starts **private** on publish regardless of what is requested. Making it public or org-shared is done
  afterwards from the share menu on the page, and only the viewer can do it (not Claude).
